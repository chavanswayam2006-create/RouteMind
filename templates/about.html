System Architecture & Engineering Design
Python 3 + Flask + Cytoscape.js

RouteMind AI is structured as a modular, decoupled AI demonstration system designed for academic rigor, transparent inspectability, and ease of demonstration on Windows systems.

Architecture Highlights:

  • Backend Engine: Python 3.x Flask server orchestrating 10 distinct, self-contained AI modules.
  • Graph Search Layer: Pure-Python implementations of Breadth-First Search (BFS), Depth-First Search (DFS), and A* Informed Search with Euclidean admissible heuristics.
  • Knowledge & Logic Layer: ISO Prolog knowledge base exporter (`.pl`) paired with a high-fidelity Python Horn-clause unification and resolution engine (with automatic SWI-Prolog detection).
  • Fuzzy Intelligence: Mamdani Centroid Controller & Sugeno Weighted-Average Inference using scikit-fuzzy with pure-Python fallbacks.
  • Machine Learning: NumPy-based Multi-Layer Perceptron (Neuro-Fuzzy delay estimator), Rosenblatt Perceptron learning rule from scratch, and Winner-Take-All competitive clustering.
  • Local NLP: Zero-dependency statistical Bigram (Micro) and Trigram (Small) language models trained on domain logistics text.

Faculty Demonstration Guide
Viva Prep
1. How to Demonstrate Route Optimality:

Go to the Dashboard. Click "Find Best Route" with A*. Point out the optimal travel time (52 min via A → D → E → G). Then run BFS (finds 3 hops via A → B → C → G: 57 min). Explain that BFS minimizes edge count, while A* minimizes accumulated travel time!

2. How to Demonstrate Blocked Avoidance:

On the dashboard or Network Editor, click "BLOCKED" on segment D-E. Re-run A*. The system automatically detours via A → B → E → G (56 min) with zero crashes!

3. Expected Viva Questions:
  • Q: Why is A* heuristic admissible?
    A: Because straight-line distance scaled by speed never overestimates true remaining road transit time: h(n) ≤ h*(n).
  • Q: What is the difference between Mamdani & Sugeno?
    A: Mamdani defuzzifies continuous fuzzy membership sets (centroid); Sugeno evaluates crisp mathematical functions (weighted average).
  • Q: Why use hybrid neuro-fuzzy?
    A: The neural network learns empirical physics from data, while the fuzzy layer enforces human-interpretable safety boundaries.
4. Academic Integrity & Data Notice:

All simulation values and neural datasets are generated synthetically for academic illustration. No live GPS or real-time road APIs are utilized. Runs 100% offline without API keys.
